## How to use

1. Retrieve the relevant project registry before substantial research.
2. Retrieve the governing project instructions as well; a registry does not replace the master guide.
3. Select sources appropriate to the specific claim. Prefer primary authorities for official rules and operational status.
4. Check the exact page, publication/update date, event/effective date and current status.
5. Record the direct source URL and what it establishes.
6. Keep facts, reported claims, inference and hypotheses separate.
7. Do not publish stale, duplicate or unverified claims.

## Registry maintenance

- Add sources only when their identity, purpose and relevance are clear.
- Record whether a source is official, independent media, specialist, competitor or traveller lead.
- Verify competitor websites and social accounts before adding them as confirmed.
- Recheck links and source ownership periodically.
- Mark unavailable or inaccessible sources rather than silently replacing them.
- A source being listed does not mean its information is current or independently verified.

## Cost control

All registries inherit the standing project spending policy: default paid spend is KES 0. No paid API, scraping, premium data, subscription, upgrade, booking or advertising operation may proceed without specific fresh approval after the provider, operation, data, estimated cost, currency, KES equivalent and free alternatives have been disclosed.

## Important

GitHub is persistent storage. Adding a file here does not automatically install it as ChatGPT memory, Custom Instructions or Project Knowledge. For repeated use, add the relevant registry file to the matching ChatGPT Project's files and instruct the project to consult it before research.
