# Productivity & Learning

Learning plans, decisions, meetings and workflows.

## Prompts

- [Practical Learning Roadmap](learning-roadmap.md) — Build a realistic sequence of skills, practice tasks, resources, feedback loops and milestones around current level, goal and available time. Use retrieval practice, spaced review and real projects.
- [Meeting Notes to Action Plan](meeting-actions.md) — Extract decisions, discussion, open questions, actions, owners and deadlines. Never infer missing owners or dates; distinguish decisions from suggestions.
- [Decision Log & Review](decision-log.md) — Record context, decision, options, criteria, evidence, assumptions, risks, owner, date and review trigger. State what would invalidate the decision.
- [Workflow Simplifier](workflow-simplifier.md) — Map a recurring workflow, identify friction and propose smallest improvements. Distinguish process changes from automation; include safeguards and success measures.

## Use standard
Provide context and source material, review outputs before acting, and keep evidence separate from assumptions. All prompts remain Draft until realistic tests and limitations are recorded.
