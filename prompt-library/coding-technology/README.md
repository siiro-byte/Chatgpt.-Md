# Coding & Technology

Requirements, code review, debugging and architecture.

## Prompts

- [Technical Requirements Clarifier](technical-requirements.md) — Convert problem into users, workflows, functional/non-functional requirements, constraints, assumptions and testable acceptance criteria. Define smallest viable scope.
- [Code Review & Risk Audit](code-review.md) — Review supplied code for correctness, security, data handling, edge cases, performance and maintainability. Give severity, location, impact, reproduction and minimal fix; avoid unnecessary rewrites.
- [Systematic Debugging](debugging.md) — Restate expected vs actual behaviour, list facts and unknowns, rank hypotheses and propose smallest safe tests. Change one variable at a time; never claim a fix without verification.
- [Practical Solution Architecture](architecture.md) — Design the simplest architecture meeting requirements. Explain components, data flow, security, failure modes, deployment, maintenance, trade-offs and phased verification.

## Use standard
Provide context and source material, review outputs before acting, and keep evidence separate from assumptions. All prompts remain Draft until realistic tests and limitations are recorded.
