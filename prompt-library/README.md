Master AI Prompt Library

A curated collection of practical, reusable and tested AI prompts.

Core principles

- Prioritise quality over quantity.
- Test prompts before approving them.
- Avoid duplication.
- Record sources and attribution.
- Require evidence for factual research.
- Protect private information.

Prompt status

- Draft — not yet tested.
- Tested — tried on a realistic task.
- Approved — tested and ready for reuse.
- Retired — no longer recommended.

Adding a prompt

Every prompt should include:

- Name and purpose
- When to use it
- Required inputs
- Complete prompt instructions
- Expected output
- Source and attribution
- Testing notes

Governing principle: Useful prompts, reliable outputs, continuous improvement.
