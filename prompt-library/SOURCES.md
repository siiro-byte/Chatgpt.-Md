# Sources, Attribution & Curation

This library is a curated collection, not a claim of ownership over third-party prompts or frameworks.

## Foundation and reference projects
- **Fabric:** https://github.com/danielmiessler/Fabric — open-source framework and crowdsourced collection of reusable AI patterns. User fork: https://github.com/siiro-byte/Fabric.
- **prompts.chat:** https://github.com/f/prompts.chat — open prompt collection. Review individual prompt provenance and licence before adapting or redistributing.
- **DAIR.AI Prompt Engineering Guide:** https://github.com/dair-ai/Prompt-Engineering-Guide — educational reference for prompt-engineering methods. User fork: https://github.com/siiro-byte/Prompt-Engineering-Guide.
- **Karpathy-inspired working principles:** maintained in [CHATGPT.md](../CHATGPT.md) and [README.md](../README.md).

## Curation rules
1. Prefer adapting a prompt to the user's real workflow over copying large collections wholesale.
2. Preserve original author, project, source URL and licence for adapted or copied material.
3. Do not remove copyright or attribution notices.
4. Check the licence of the source repository and relevant file before redistributing contents.
5. Clearly label original, adapted and externally sourced material.
6. Do not claim a prompt has been tested unless a realistic test and result are recorded.
7. Link source projects rather than duplicating entire repositories.
