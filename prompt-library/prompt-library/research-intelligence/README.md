# Research & Intelligence

Prompts for evidence-based research, investigation, analysis and decision-making.

## Specialist areas

1. Deep Research
2. Fact Checking & Verification
3. News Monitoring
4. Competitive Intelligence
5. Data Analysis
6. Source Evaluation
7. Risk Assessment
8. Trend Analysis
9. Report Writing

## Quality standards

- Prioritise primary and authoritative sources.
- Verify publication dates and event dates.
- Separate confirmed facts from assumptions.
- Identify conflicting evidence.
- Cite sources for factual claims.
- Never invent information.
- State research limitations.

## Approval rule

A prompt must be tested before receiving Approved status.
